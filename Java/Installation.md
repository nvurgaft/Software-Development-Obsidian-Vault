There are several ways to install Java on your host machine
### WSL

You must have elevated privilege to install Java on a Linux environment

To install [OpenJDK](https://openjdk.org/) version 17

```shell
sudo apt install openjdk-17-jdk
```

To test if Java was successfully installed and is in your PATH, run 

```shell
java --version
```

To test if Java compiler was successfully installed and is in your PATH, run

```shell
javac --version
```

### Windows 

On windows you can download an installer via the following link https://www.oracle.com/java/technologies/downloads/
